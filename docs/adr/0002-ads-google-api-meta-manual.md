# Google Ads pela API no env; Meta digitada por mês

O aspen-site já tem OAuth e token da conta Google Ads; este app não. Tokens de anúncio não entram em Configurações — o padrão do Aspen é env fora do repo. Meta só tem pixel, não conta de anúncio, então o gasto da Meta é digitado em Resultados por mês calendário. A API da Meta fica para depois. Em 7d/30d a Meta não entra, para não ratear um bolo mensal.

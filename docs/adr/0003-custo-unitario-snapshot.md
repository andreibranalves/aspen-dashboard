# Custo unitário no produto, fotografado no Pedido

Um número por SKU, não faixa. Na hora do Pedido o custo vai para a linha; mudar o cadastro depois não reescreve o Lucro de janeiro. Custo vazio vale 0. Quando a tabela chegar, Pedidos antigos recebem o custo atual uma vez. Sem isso o Lucro só existiria daqui pra frente.

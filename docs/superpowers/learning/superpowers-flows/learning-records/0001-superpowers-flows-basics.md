# O agente não adivinha a fase

O usuário descobriu que jogar um spec pronto em uma nova sessão e dizer "faça" faz o agente recomeçar o ciclo de `brainstorming`, porque ele não tem como saber que o spec já foi aprovado.

Implicação para futuras sessões: sempre nomear a fase e a skill explicitamente ("spec aprovado, use writing-plans", "plano pronto, use executing-plans"). O formato mínimo de contexto é: caminho do projeto + caminho do spec/plano + estado de aprovação + skill desejada.

Lição 2 — Retomando trabalho em outra sessão

Objetivo: fazer com que um agente em sessão nova continue de onde parou, sem recomeçar o brainstorming.

O problema

Sessões são isoladas. Quando você diz apenas "faça" e anexa um spec, o agente novo não sabe:

  • Se o spec já foi aprovado.
  • Se já existe plano de implementação.
  • Se parte do trabalho já foi feita.

Por isso ele pode cair no loop de brainstorming e reescrever o spec.

A solução: contexto mínimo

Sempre informe, na primeira mensagem da nova sessão:

  1. Caminho do projeto.
  2. Caminho do spec ou plano.
  3. Estado atual: spec aprovado? Plano existe? Algo já foi implementado?
  4. Skill desejada.

Prompts por situação

Prompt

`docs/superpowers/specs/2026-06-25-tighten-frontend-types-design.md`
já foi aprovado. Use a skill writing-plans para criar o plano de
implementação em `docs/superpowers/plans/2026-06-25-tighten-frontend-types-plan.md`.
Não refaça o spec. Não execute código ainda.

Situação B — Plano pronto, executar

Prompt

Situação C — Trabalho já começou, retomar

A Tarefa 1 e 2 já foram concluídas e commitadas. Retome a partir da

Lição 1 — Fluxo em uma única sessão

Objetivo: saber conduzir uma ideia até o código dentro da mesma conversa, sem que o agente pule etapas.

Cenário

Você tem uma ideia nova e quer implementá-la. A sessão está vazia: o agente ainda não conversou com você sobre isso.

Passo a passo

1. Comece com brainstorming

Não peça código ainda. A skill vai fazer perguntas, propor abordagens e escrever um spec.

Prompt
No projeto /home/andrei/projects/aspen-dashboard, quero [descreva a ideia].
Use a skill brainstorming para criar o spec.
Não escreva código.
Por que não pular? O spec é o contrato. Se você aprovar um spec ruim, o plano e o código vão refletir esse erro.

2. Aprove o spec

O agente apresentará seções e pedirá aprovação. Responda sim ou peça ajustes. Quando aprovar, ele escreve o arquivo em docs/superpowers/specs/.

3. Peça o plano com writing-plans

Prompt
O spec `docs/superpowers/specs/YYYY-MM-DD-<tema>-design.md`
já está aprovado. Use a skill writing-plans para criar o plano de
implementação. Não execute ainda.

4. Execute com subagent-driven-development

Como você está na mesma sessão, essa skill é geralmente a melhor escolha: um subagente por tarefa, com revisão entre elas.

Prompt
Execute o plano `docs/superpowers/plans/YYYY-MM-DD-<tema>.md`
usando a skill subagent-driven-development. Valide cada tarefa e
rode os checks finais.

5. Finalize com finishing-a-development-branch

Depois que tudo passar, o agente oferece opções de merge/PR.

Resumo visual

brainstorming → writing-plans → subagent-driven-development → finishing-a-development-branch

Exercício rápido

Releia o cheat sheet e identifique qual skill está faltando neste pedido:

"Implemente a feature X no projeto Aspen."

Resposta: está faltando brainstorming e writing-plans. O agente pode até executar, mas sem spec/plano o resultado será imprevisível.

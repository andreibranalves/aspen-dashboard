# Recursos: Fluxos Superpowers

## Knowledge

- [using-superpowers — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/using-superpowers/SKILL.md)
  Regra de ouro: invocar a skill relevante antes de qualquer resposta/ação. Define prioridade entre instruções do usuário, skills e prompt padrão.

- [brainstorming — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/brainstorming/SKILL.md)
  Processo de design/spec: explore contexto, pergunte, proponha abordagens, escreva spec em `docs/superpowers/specs/`, revise e só então invoque `writing-plans`.

- [writing-plans — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/writing-plans/SKILL.md)
  Transforma spec aprovado em plano de implementação passo a passo em `docs/superpowers/plans/`.

- [executing-plans — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/executing-plans/SKILL.md)
  Executa um plano já escrito em sessão separada, com checkpoints de revisão.

- [subagent-driven-development — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/subagent-driven-development/SKILL.md)
  Executa plano na sessão atual, um subagente por tarefa, com revisão após cada uma.

- [dispatching-parallel-agents — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/dispatching-parallel-agents/SKILL.md)
  Dispara múltiplos subagentes em paralelo para problemas independentes.

- [verification-before-completion — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/verification-before-completion/SKILL.md)
  Regra: nenhuma afirmação de conclusão sem evidência de verificação fresca.

- [finishing-a-development-branch — SKILL.md](../../../../../../../.kimi-code/plugins/managed/superpowers/skills/finishing-a-development-branch/SKILL.md)
  Como integrar o trabalho (merge local, PR, manter branch, descartar).

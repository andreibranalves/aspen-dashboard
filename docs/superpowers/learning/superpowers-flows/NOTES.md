# Notas de ensino

## Preferências do usuário

- Quer uma "colinha" rápida, não um curso longo.
- Já teve problema: jogou um spec em nova sessão e o agente reiniciou `brainstorming`.
- Interesse imediato: prompts corretos para cada transição de fase, single vs. multi-sessão.

## Pontos de atenção

- Enfatizar que "faça" sozinho é ambíguo. O agente não sabe se deve especificar, planejar ou implementar.
- Mostrar o formato mínimo de contexto em nova sessão: caminho do projeto + caminho do spec/plano + estado de aprovação + skill desejada.
- Deixar claro que `brainstorming` só deve ser usado quando ainda não existe spec aprovado.
